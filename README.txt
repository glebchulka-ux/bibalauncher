BIBA LAUNCHER

ГОТОВЫЙ exe БЕЗ PYTHON (бесплатно, через GitHub)
  Python на вашем компьютере не нужен: exe собирает сам GitHub.
  1) Зарегистрируйтесь на github.com и нажмите New repository. Имя любое, например biba-launcher, доступ Public.
  2) В репозитории: Add file -> Upload files. Перетащите все файлы из этой папки (и папку .github), нажмите Commit changes.
     Если папка .github не загрузилась: Add file -> Create new file, имя .github/workflows/release.yml,
     вставьте текст из файла release.yml.txt и нажмите Commit changes.
  3) Вкладка Actions -> Build release -> Run workflow -> версия 1.0.0 -> Run workflow.
     Если GitHub просит разрешить запуск Actions, нажмите зелёную кнопку.
  4) Через 5-10 минут в разделе Releases (справа на главной странице репозитория) появится BibaLauncher.exe.
     Скачайте его и запускайте двойным кликом. Ярлык: правая кнопка -> Отправить -> Рабочий стол.

АВТООБНОВЛЕНИЕ
  Лаунчер проверяет релизы вашего репозитория при запуске и раз в 6 часов. Нашёл новую версию: скачал, проверил
  контрольную сумму, заменил себя и перезапустился. Если в это время идёт игра, ждёт её конца.
  Как выпустить обновление: замените файлы в репозитории новыми и снова Actions -> Build release -> Run workflow
  с бо́льшим номером версии (например 1.0.1). У всех лаунчер обновится сам.
  Источник обновлений можно поменять в Настройках: владелец/репозиторий на GitHub или ссылка на update.json
  (формат: {"version": "1.0.1", "url": "https://.../BibaLauncher.exe", "sha256": "..."}).

ЕСЛИ PYTHON УЖЕ УСТАНОВЛЕН
  INSTALL.bat собирает exe у вас на компьютере, ставит его в %LOCALAPPDATA%\BibaLauncher и делает ярлыки.
  (Обновления при такой сборке работают, когда в Настройках указан репозиторий.)
  UNINSTALL.bat удаляет программу, настройки и миры остаются.
  start.bat запускает без сборки, build_exe.bat только собирает dist\BibaLauncher.exe.

ГДЕ ХРАНИТСЯ
  Настройки, скины, обложки и логи: C:\Users\ВашеИмя\.biba-launcher (старая папка .glebster переносится сама).
  Сборки (отдельные папки с модами и мирами): .biba-launcher\instances
  error.log - ошибки интерфейса, game.log - вывод игры. Если что-то сломалось, пришлите эти файлы.

ВХОД ЧЕРЕЗ MICROSOFT
  В окне аккаунта выберите вкладку Microsoft, вставьте Client ID и нажмите «Войти через Microsoft».
  Нужен Client ID приложения Azure, одобренного Mojang (кнопки «Как получить» и «Форма Mojang»).
  Без одобрения Microsoft отвечает «Invalid app registration». Оффлайн и Ely.by от этого не зависят.
  Токены входа хранятся в config.json, не показывайте этот файл другим.
